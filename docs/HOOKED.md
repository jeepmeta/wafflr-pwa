# Wafflr × Hook Model

**Ethics:** Facilitator — makers use it; it shortens group decision pain. No infinite feed, no dark patterns mid-swipe. Ads only post-results.

## Loop score (target 9–10)

| Phase | Implementation | Strength |
|-------|----------------|----------|
| **Internal trigger** | "What should we do / eat / watch?" paralysis in friend groups | Strong |
| **External trigger** | Shared code / QR, Your Rooms badge, install prompt | Strong |
| **Action** | Create or Join → swipe (≤60s sessions) | Strong |
| **Variable reward** | Unknown winner, confetti, character beats, wink | Strong |
| **Investment** | Device room registry, cards added, votes cast | Medium–Strong |

## Rules for new features

1. **Never** put friction before first reward (results / laugh).
2. Investment (cards, shares) comes **after** a win when possible.
3. Variable reward stays finite per room — natural stop when status = completed.
4. External triggers (share, rooms list) must deep-link to one obvious action.
5. No engagement that relies on user regret.

## Extending the loop

- Streaks / "rooms this week" = optional Self reward (Phase 8+).
- Mass broadcast rooms = Tribe reward at scale (still one swipe action).
