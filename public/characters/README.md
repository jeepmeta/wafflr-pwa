# Wafflr Character Assets

**Canonical cast:** Butters the Waffle · Barron Bacon · Strawberry Sue · Hugh Blueberry · Eggin Targarian · O.J.

Retired: Salty Sam, Sir Cha-Cha, Pip & Dip, Madame Mochi.

Starter SVG poses and sprite sheets live in each character folder. Final PNG checklist is in the project artifacts `assets/characters/README.md`.

Sprite sheets use **256×256** frames in horizontal strips for `steps(n)` CSS animations.
